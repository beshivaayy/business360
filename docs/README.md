# Business360 portfolio website

A responsive, single-page portfolio landing page is available at [index.html](./index.html).

## Publish with GitHub Pages

The source file is in the `docs/` folder. To publish it:
1. Open the repository's **Settings**.
2. Open **Pages** under **Code and automation**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/docs**, then save.
5. Wait for GitHub Pages to finish deployment. The published URL will appear in the Pages settings.

The HTML page is committed, but the site is **not claimed to be live** until Pages is enabled and GitHub confirms deployment.

## Editing
The page uses embedded CSS and no external framework or image dependency. Update `index.html` directly; keep the case-study links and synthetic-data disclosure accurate.
