# Business360 Templates

Reusable working files for the portfolio case studies. These are blank data-capture tools, not datasets or evidence of completed work.

| Template | Use |
|---|---|
| [Case-study template](./case-study-template.md) | Structure a decision-oriented project |
| [Operations KPI tracker](./operations-kpi-tracker.csv) | Capture batch-level workload, quality, rework, and delivery data |
| [GTM funnel tracker](./gtm-funnel-tracker.csv) | Track target accounts, engagement, opportunities, pilots, and contracts |
| [Strategy options matrix](./strategy-options-matrix.csv) | Compare strategic alternatives against explicit criteria |
| [AI use-case scorecard](./ai-use-case-scorecard.csv) | Screen AI opportunities for value, feasibility, data readiness, risk, and oversight |

## Usage rules
- Define each metric and its denominator before entering data.
- Keep source references and dates with any factual input.
- Do not average percentages across groups without checking denominators.
- Treat scores as structured judgement, not objective truth; record rationale and run sensitivity checks.
- Never enter confidential client, employee, or personal data into a public repository.
- Keep synthetic examples clearly labelled and separate from actual operating records.
